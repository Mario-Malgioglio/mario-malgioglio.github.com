## Proyectos

### 🔒 KSec – Auditor de servidores
Permite analizar cualquier sitio o servicio web en tiempo real, evaluar su postura de seguridad, obtener un puntaje global (0 a 100), generar reportes ejecutivos en PDF y obtener plantillas de configuración de remediación inmediata para servidores populares (Nginx, Apache, Caddy, Cloudflare y Node.js/Express).

[Ver proyecto →](https://github.com/Mario-Malgioglio/KSec-Web-Security)

---

### 📡 Wi‑Fi Security & Protocol Auditor
Suite defensiva y auditor de protocolos inalámbricos IEEE 802.11 (WPA3, WPA2, WEP, Open, OWE). Desarrollada en Golang puro (sin dependencias externas) con interfaz visual reactiva, modo consola CLI, API REST JSON, exportación CSV y liberación determinista de memoria RAM al cerrar el navegador.

[Ver proyecto →](https://github.com/Mario-Malgioglio/Wi-Fi-Security-Protocol-Auditor)
